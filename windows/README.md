# 🖥 Roblox Images Fix (RF) — Windows Edition

Чинит иконки/обложки/аватарки **в самом клиенте Roblox и в Roblox Studio**.

## Быстрый старт

1. Двойной клик по **`RobloxCDNFix.bat`** → согласись на права администратора.
2. В меню выбери **1** (Установить фикс + автообновление).
3. Полностью закрой Roblox (включая трей) и открой заново.

Всё. Скрипт сам найдёт живые IP через DNS-over-HTTPS, проверит каждый
реальным соединением, пропишет в hosts и будет обновлять их каждые 6 часов.

## Что делает под капотом

| Шаг | Зачем |
|---|---|
| DoH-запрос (Cloudflare → Google) | узнаёт актуальные IP `tr.rbxcdn.com` по цепочкам `traws/trak.rbxcdn.com`, минуя DNS провайдера |
| Тест каждого IP через `curl --resolve` | соединяется с реальным TLS-сертификатом — в hosts попадает только реально работающий IP |
| Запись в `C:\Windows\System32\drivers\etc\hosts` | клиент Roblox использует системный DNS → начинает видеть картинки |
| Задача планировщика (6 ч + при входе) | CloudFront меняет IP — фикс сам обновляет их, не «умирает» как ручные гайды |

Все изменения в hosts стоят между маркерами `# >>> roblox-images-fix >>>` и
`# <<< roblox-images-fix <<<` и удаляются одной командой **5** (Удалить фикс) —
никакого мусора не остаётся.

## Параметры PowerShell (для тех, кто любит консоль)

```powershell
.\RobloxCDNFix.ps1 -Install   # установить + планировщик
.\RobloxCDNFix.ps1 -Apply     # только обновить IP сейчас
.\RobloxCDNFix.ps1 -Status    # что прописано, живы ли IP
.\RobloxCDNFix.ps1 -Test      # диагностика, ничего не меняет
.\RobloxCDNFix.ps1 -Remove    # полностью убрать фикс
```

## Не помогло?

- Перезапусти Roblox **полностью** (проверь трей) — клиент кэширует DNS.
- `-Status` покажет, жив ли прописанный IP; если мёртв — `-Apply`.
- Если даже `-Test` не находит живых IP — твой провайдер блокирует по IP/SNI:
  тогда hosts не спасёт, нужен zapret/GoodbyeDPI или VPN (см. главный README).
