# 📱 Roblox Images Fix — Android APP

**Собственное Android-приложение проекта** (не модификация Roblox!). Одна кнопка — и иконки/обложки/аватарки в приложении Roblox загружаются. Без root, без VPN-серверов, без настроек системы.

> ⚠️ Это исходный код. Готовый APK собирает GitHub Actions автоматически — см. [«Как получить APK»](#-как-получить-готовый-apk).

---

## 🧠 Как это работает (честно и по-простому)

Приложение поднимает **локальный точечный туннель** (стандартный Android-API `VpnService`), в который уходит **только DNS-трафик** — маршрут `/32` на внутренний DNS-сервер приложения. Весь остальной интернет телефона идёт напрямую, мимо туннеля, без потери скорости.

Внутри туннеля приложение:

1. **Перехватывает DNS-запросы** к `tr/t0/t1/t5.rbxcdn.com` (домену всех картинок Roblox, заблокированному в РФ).
2. Отвечает на них **IP-адресами официального CloudFront-зеркала** — это та же самая CDN Roblox, отдающая **байт-в-байт те же файлы**, просто по незаблокированному имени (`dXXXX.cloudfront.net`). Roblox-приложение даже не замечает подмены: TLS-сертификат зеркала валиден для `rbxcdn.com`.
3. Все остальные DNS-запросы переправляет на зашифрованные апстримы **Cloudflare → Google (DoH)** и возвращает ответы как есть — поэтому работает даже если провайдер блокирует обычные DNS.

Список зеркал приложение **сам обновляет через DoH** каждые 10 минут — если Roblox сменит CDN-дистрибуцию, APP подстроится (плюс страховочные hardcoded-IP).

### Почему это не «VPN» в привычном смысле

Никаких внешних серверов: туннель существует только внутри телефона. Скорость игр и сёрфинга не падает. В шторке — обычное Android-уведомление «фикс включён».

### Почему это безопасно для аккаунта

Приложение **не модифицирует** Roblox (никаких модов APK, никаких рисков античита), не собирает данных, не проксирует трафик через чужие сервера. Весь код открыт — ~700 строк читаемой Java.

## 📥 Как получить готовый APK

### Вариант А — через GitHub Actions (нужен только браузер)

1. Выложи репозиторий на GitHub (см. [PUBLISH.md](../PUBLISH.md)).
2. Открой вкладку **Actions** → выбери **Build APK** → **Run workflow** → **Run**.
3. Через 3–5 минут в запуске появится артефакт **RobloxImagesFix-apk** — скачай ZIP, внутри `RobloxImagesFix.apk`.
4. Хочешь APK в разделе Releases? Сделай тег: `Releases → Draft new release → тег v1.0.0 → Publish` — Actions соберёт и приложит APK автоматически.

### Вариант Б — собрать самому

```bash
cd android-app
./gradlew :app:assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```
Нужны JDK 17 и Android SDK (проще всего — Android Studio → Open project).

## 📲 Установка на телефон

1. Скинь `RobloxImagesFix.apk` на телефон и открой.
2. Android спросит про установку из неизвестных источников — разреши (приложение без Google Play — это нормально для open-source, весь код открыт).
3. Открой приложение → **ВКЛЮЧИТЬ** → система спросит разрешение на VPN (стандартный диалог Android) → **ОК**.
4. **Полностью закрой Roblox** (смахни из недавних) и открой заново.
5. Нажми **«Проверить»** в приложении — увидишь ✅, если фикс работает.

Выключить — кнопкой **ВЫКЛЮЧИТЬ**, ничего в системе не остаётся.

## 🧪 Технические детали

| | |
|---|---|
| Язык | Java (без нативных библиотек, без Kotlin — быстрая надёжная сборка) |
| minSdk | 24 (Android 7.0) |
| targetSdk | 34 (Android 14) |
| Разрешения | VPN (системный диалог), уведомление о работающем сервисе |
| Переписываемые хосты | `tr`, `t0`, `t1`, `t5` `.rbxcdn.com` → CloudFront-зеркала |
| Апстримы DNS | DoH Cloudflare → DoH Google → UDP 1.1.1.1 |
| Кэш DNS | 60–120 сек в памяти |

### Ограничения

- Приложение перехватывает **системный DNS**. Если какое-то приложение делает свой DoH в обход системы (напр., Chrome с «безопасным DNS») — на него фикс не подействует. Roblox использует системный резолв, так что для него работает.
- Если оператор блокирует сами IP CloudFront (блокировка глубже DNS) — как и любой DNS-метод, не поможет; тогда только VPN.
- На некоторых «экзотических» китайских прошивках DNS-only VPN-режим может вести себя иначе — если наткнёшься, открой Issue (это чинится).
