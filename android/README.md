# 📱 Roblox Images Fix (RF) — Android Edition

Чинит иконки/обложки/аватарки **в приложении Roblox на Android** (без root).

## Почему на телефоне это работает иначе

Приложение Roblox качает картинки с того же заблокированного `tr.rbxcdn.com`.
На Android нельзя воткнуть юзерскрипт в чужое приложение, но в большинстве
случаев блокировка на мобильных сетях — **DNS-уровня** (подмена/блокировка
резолва). Значит, чинится **сменой DNS на зашифрованный (DoH/DoT)** — без root,
без VPN, без потери скорости.

## 🔍 Шаг 0. Диагностика: у тебя какой случай?

Открой в браузере телефона адрес: **https://tr.rbxcdn.com/**

| Что видишь | Что это значит | Что поможет |
|---|---|---|
| «Не удаётся найти адрес сервера» / ERR_NAME_NOT_RESOLVED | DNS-блокировка | ✅ Способы 1–3 ниже |
| Бесконечная загрузка / «Сайт недоступен» по таймауту | Блокировка по IP/SNI (глубже DNS) | ❌ DNS не поможет → только VPN (см. конец) |
| Какая-то ошибка JSON/404 | 🎉 Домен вообще не заблокирован у твоего оператора | Проблема в другом — кэш приложения |

> Способы расположены от простого к продвинутому. Пробуй по очереди.

---

## Способ 1. Приватный DNS (встроен в Android, 2 минуты)

1. **Настройки → Сеть и интернет → Приватный DNS** (Private DNS).
   На некоторых прошивках: **Настройки → Подключения → Другие настройки → Приватный DNS**.
2. Выбери **«Имя хоста провайдера DNS»** и впиши по очереди (после каждой
   смены — перезапусти Roblox):

   | Хостнейм | Чей это DNS |
   |---|---|
   | `dns.quad9.net` | Quad9 — пробуй первым |
   | `dns.opendns.com` | OpenDNS — по отзывам чаще всего работает |
   | `dns.adguard-dns.com` | AdGuard DNS |

3. Не помогло — попробуй следующий из списка.

Затем: полностью закрой Roblox (смахни из недавних) и открой заново.
Если не помогло сразу — включи на 10 секунд «Авиарежим» (это сбросит DNS-кэш) и снова открой.

## Способ 2. То же самое одной командой с ПК (ADB)

Если копаться в настройках лень (или прошивка ограничивает меню) — подключи
телефон к компьютеру по USB с отладкой по ADB и запусти наш скрипт:

**Windows** (нужен platform-tools с adb):
```bat
android\set-private-dns.bat opendns
```

**Linux / macOS:**
```bash
./android/set-private-dns.sh opendns
```

Аргументы: `quad9`, `opendns`, `adguard`, любой свой хостнейм, `off` — выключить,
`status` — посмотреть, что сейчас стоит.

> Это ровно те же настройки из Способа 1, просто через `adb shell settings put`.

## Способ 3. Приложение RethinkDNS (гибко, без root)

Если провайдер режет даже шифрованный системный DNS, локальный «VPN без VPN»
спасает:

1. Установи **RethinkDNS** (Google Play или F-Droid) — open-source.
2. В настройках DNS выбери **DoH-провайдера**: `Quad9` или добавь свой URL
   `https://doh.opendns.com/dns-query`.
3. Включи защиту. В списке приложений можно применить только к Roblox —
   остальные будут ходить напрямую.
4. Перезапусти Roblox.

Аналоги, если RethinkDNS не зайдёт: **Intra** (простой, только DoH), **Personal DNSfilter**.

## ❗ Если ничего не помогло (блокировка по IP/SNI)

Значит, твой оператор блокирует не DNS, а само соединение. Тогда:

- **VPN** — самый надёжный способ (любой, с серверами вне РФ).
- Эконом-вариант: локальные DPI-обходчики для Android (например, приложения
  на базе sing-box / zapret-подобных правил) — это для продвинутых,
  настраивай по актуальным инструкций сообщества.

## ❔ FAQ

**Безопасно ли менять Private DNS?**
Да, это штатная функция Android. Сайты открываются как обычно, просто адреса
теперь узнаются через зашифрованный DNS. Вернуть обратно: `off` / «Нет».

**Почему способ 1 иногда не работает, а RethinkDNS работает?**
Некоторые операторы перехватывают и DoT (порт 853) на «приватный DNS».
RethinkDNS гонит DoH через HTTPS-порт 443, который заблокировать сложнее.

**Иконки починились, а внутриигровые картинки (в клиенте игры) нет?**
Перезапусти Roblox полностью и включи-выключи авиарежим — приложение
кэширует старые неудачные ответы.

**А iPhone?**
На iOS без джейлбрейка системный hosts недоступен. Рабочий вариант —
приложения типа DNSecure / NextDNS (DoH-профиль) или VPN.
