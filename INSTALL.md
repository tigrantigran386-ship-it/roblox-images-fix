# 📥 Подробная установка (для новичков)

Выберите ОДИН вариант. Если сомневаетесь — берите **Вариант 1 (юзерскрипт)**: он самый умный и самонастраивающийся.

---

## Вариант 1. Юзерскрипт через Tampermonkey

### Шаг 1. Установите Tampermonkey

| Браузер | Откуда ставить |
|---|---|
| Google Chrome / Edge / Яндекс.Браузер / Opera | [Chrome Web Store — Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Mozilla Firefox | [Firefox Add-ons — Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/) |

Нажмите **Установить** → подтвердите. После установки в правом верхнем углу браузера появится чёрно-серый квадратик Tampermonkey.

### Шаг 2. Установите сам скрипт

1. Откройте на GitHub файл [`userscript/roblox-images-fix.user.js`](userscript/roblox-images-fix.user.js).
2. Нажмите кнопку **Raw** (откроется «простыня» кода).
3. Tampermonkey сам перехватит страницу и покажет окно установки со вкладкой **Settings / Настройки**.
4. Нажмите **Установить**.

> Если окно не появилось: кликните по иконке Tampermonkey → **Добавить новый скрипт** → сотрите шаблон → вставьте весь код из файла → `Ctrl+S`.

### Шаг 3. Проверьте

1. Откройте https://www.roblox.com/discover (или любую страницу с играми).
2. Обновите страницу с очисткой кэша: **Ctrl + F5**.
3. Иконки игр и аватарки должны появиться.
4. (Необязательно) Нажмите **F12 → Console** — увидите зелёный лог:
   `[Roblox Images Fix] v1.0.0 активен`, а также строки «зеркализировано: …».

## Вариант 2. Расширение без Tampermonkey (Chrome / Edge / Яндекс.Браузер)

Работает так же, но ставится «железно»: просто перенаправляет запросы, без исполняемого кода на странице.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** → распакуйте.
2. Откройте в браузере адрес:
   - Chrome / Edge / Яндекс: `chrome://extensions`
3. Включите переключатель **Режим разработчика** (справа вверху).
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `extension` из распакованного архива (ту, где лежит `manifest.json`).
6. Перезагрузите страницу Roblox с **Ctrl + F5**.

> Чтобы скрыть иконку расширения с панели: кликните по «пазлику» → нажимайте на булавку.

## Вариант 3. Телефон / планшет

- **Android — приложение Roblox (рекомендуется):** наше собственное приложение [`android-app/`](android-app/) — скачай APK из GitHub Actions, нажми ВКЛЮЧИТЬ. Подробности в [android-app/README.md](android-app/README.md).
- **Android — альтернатива без установки:** гайд [android/README.md](android/) — Private DNS за 2 минуты или ADB-командой.
- **Android — сайт Roblox в браузере:** Firefox + Tampermonkey → Вариант 1; либо Kiwi/Edge Canary + Вариант 2.
- **iOS:** браузер с юзерскриптами (например, Userscripts для Safari) → Вариант 1.

## Вариант 4. Клиент Roblox на Windows (не браузер!)

Запустите [`windows/RobloxCDNFix.bat`](windows/) от имени администратора → пункт 1.
Он сам найдёт живые IP, пропишет их в hosts и будет обновлять их по расписанию.
Подробнее — [windows/](windows/) и главный README.

## 🛠 Если не заработало

1. **Жёстко обновите страницу**: `Ctrl + F5`.
2. **Ставили раньше фикс через файл `hosts`?** Удалите строку `tr.rbxcdn.com` из
   `C:\Windows\System32\drivers\etc\hosts` и выполните `ipconfig /flushdns` —
   старый IP может конфликтовать с зеркалом.
3. **Отключите другие блокировщики** (AdGuard/uBlock) для сайта roblox.com — они могут резать и наши запросы.
4. Откройте **F12 → Console**: есть ли зелёный `[Roblox Images Fix]`?
   - Лога нет → скрипт не установлен/выключен: проверьте иконку Tampermonkey — там должно быть «1».
   - Лог есть, картинок нет → смотрите вкладку **Network**, отфильтруйте `cloudfront`: что показывает статус? (ERR_NAME_NOT_RESOLVED = провайдер режет и CloudFront-имя этого дистрибутива — ждите автопереключения зеркала или напишите Issue).
5. Проверьте, что страница именно `*.roblox.com` — на другие сайты скрипт не влияет.

## 🗑 Как удалить

- Юзерскрипт: иконка Tampermonkey → Панель управления → корзина напротив скрипта.
- Расширение: `chrome://extensions` → «Удалить».
- Ничего в системе не остаётся — ни файлов, ни настроек.
