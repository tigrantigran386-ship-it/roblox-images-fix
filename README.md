**Android-приложение, которое чинит загрузку картинок Roblox в РФ** — иконки игр, обложки, аватарки на главной, в каталоге и внутри плейсов. Без VPN, без root, без риска для аккаунта.

> ❌ Без фикса: серые квадраты вместо обложек, вечная загрузка иконок, подтормаживающий плейс
> ✅ С фиксом: всё грузится — а приложение само подстраивается, если Roblox сменит свои CDN

### Установка

1. Скачайте APK и откройте его на телефоне (Android 7.0+)
2. Разрешите установку из неизвестных источников (приложение распространяется вне Google Play — весь код открыт)
3. Откройте приложение → **ВКЛЮЧИТЬ** → подтвердите системный запрос VPN
4. **Полностью перезапустите Roblox** (смахните из недавних)
5. Кнопка **«Проверить»** покажет, что фикс работает ✅

Выключение — той же кнопкой. Ничего в системе не остаётся.

## 🧠 Как это работает

Картинки Roblox отдаются через домен `*.rbxcdn.com`, который в РФ блокируется. Приложение поднимает **локальный точечный туннель** (штатный Android-API `VpnService`), в который попадает **только приложение Roblox и только DNS-запросы**:

1. Запросы к `rbxcdn.com` получают в ответ **IP официального CloudFront-зеркала** — той же самой CDN Roblox, отдающей те же файлы по незаблокированному имени
2. Все остальные DNS-запросы пересылаются обычному DNS оператора — интернет работает как раньше
3. Список зеркал (28 хостов: `tr`, `t0–t7`, `c0–c7`, `sc0–sc7`, `apis`, `fts`, `clientsettings`, `static`) приложение **само обновляет**, а если Roblox заведёт новый хост — **сама найдёт его зеркало** в фоне

Это **не мод Roblox**: клиент не модифицируется, античит ничего не видит, аккаунту ничего не грозит. Никаких внешних серверов — туннель существует только внутри телефона.

## ⏱ Честно про микрозадержки

При появлении нового игрока/объекта Roblox иногда открывает новое соединение к зеркалу: TCP + TLS-рукопожатия при RTT ~130 мс дают **~0.4–0.5 с единоразовой задержки**, дальше соединение переиспользуется и всё летает. Это физика метода (TLS-криптографию между Roblox и CloudFront убрать нельзя), приложение уже выжало максимум на своей стороне: мгновенный DNS, ближайшие IP первыми, полное покрытие хостов.

## 🛡 Приватность и безопасность

- **0 внешних серверов** — трафик не покидает телефон (кроме самих запросов DNS/картинок)
- **0 собираемых данных**, никаких разрешений сверх VPN и уведомления
- **Не модифицирует Roblox** — нет риска бана (это не мод APK)
- Весь код открыт: ~700 строк читаемой Java без единой внешней зависимости
